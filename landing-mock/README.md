# FoodAllo — Public site (ready to use)

Fair allocation of food and essentials when markets fail. Public interest · free · no profit motive.

## Open locally
```bash
cd landing-mock
python3 -m http.server 8765
```
Then: http://127.0.0.1:8765/

- Home: `/`
- Market disrupted: `/demo.html?preset=markt`
- Shortage week: `/demo.html` (default)
- No smartphone: `/analog.html`
- Elimination engine: `/eliminationsmaschine.html`
